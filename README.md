## 💫 About Me

Currently working on an arm-handling robot for automated chemistry research. It has two layers:
- a **hardware control layer** (`lh_engine/`) exposing the robot's serial protocol as a REST API with a CSV-backed state store and a hardware-free simulator
- a **research orchestration layer** that plans and executes crystallization experiments — anti-solvent addition, cocrystallization, and solubility screening — across a 96-tube rack, while a RoMa-mounted camera images each tube over time and logs every transfer and image to timestamped JSON for downstream analysis
